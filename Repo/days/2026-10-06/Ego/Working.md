## rem Working

完整闭环：岗位 / 任务 -> Mission / EVAL / 工单 -> 推演 / 执行 -> 影页 -> Human  判断 -> 修订内容或执行 Tools -> 结果 / evidence -> EVAL / 对齐 / 再行动 -> 完成 / 交接 / 沉淀。

VSC + Copilot 为客户端；Sol / Luna 分别目标处理 Mission 与软件自身。来源变化、scope、权限、模型实际运行分开留证。HTML 只读，Human 通过可回查来源在 VSC 或 owning Tools 执行。

场景 handoff 指明对象 / diff / evidence：业务任务内容由 Mission flow 管理，软件 规则 / skills / adapter 由 rem maintenance flow 管理。最终 acceptance / 岗位确认唯 Human；self-change 测试不等于业务任务完成。模型不可用、越权、secrets / cost  未批准均停止对应动作。
