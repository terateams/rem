RA仓规的 Shaping（打磨）

Shaping (打磨) is the work of improving AGENTS.md in small steps. Player The word comes from the Player. The method below is SI.

  • Shape AGENTS.md in small commits. One rule per commit. Write the reason in the commit message.
  • Add a rule only after an agent breaks the expected behavior. Do not add rules in advance.
  • Remove a rule that no agent needs. Short files are easier for agents to follow. SI
  • After each shaping step, run sh scripts/ra-check.sh. After each large step, run the acceptance test (see "Init").
  • Record the RA仓规 version in scripts/ra-check.sh (RA_VERSION). Change it when you adopt a new version.
