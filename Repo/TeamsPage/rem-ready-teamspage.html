就绪判据

Repo本机 HEAD 与新鲜核验的所选 GitHub 分支提交一致。工作区和编辑器缓冲区另报 clean、dirty-known 或 unknown；已知本地改动不改变提交对齐。
RAAGENTS.md 是唯一控制性 SI 指令；RAP 与其边界一致；RCI carrier 已退役；ra-check.py 通过。运行时规则 / Skill 加载另行记录，未知时只阻断依赖它的任务。
RW按任务核验设备、操作系统、网络、VSC、扩展、终端、环境与工具。SI 观察和 Player/Human 声明均可作证，必须标明来源；声明不冒充独立测量。
Mission当前任务来源有证据表明任务可以开工，并明确责任、scope、交付、验收、证据、权限、成本与 stop rule。不要求统一状态标签；未绑定任务时只报 Repo/RA/RW，不给具体任务标 READY。
结果READY 表示本任务必需门槛均通过；READY_WITH_LIMITS 表示未知项不影响本任务；ANDON 表示路径选择尚未完成；BLOCKED 表示任务依赖的门槛失败或未知。

解决 ANDON 后保留已知 dirty paths；不要求清理、commit 或 push。无关且不触及这些路径的任务可继续，冲突任务才阻断。

请求的 Copilot picker label 为 Luna Max 872K；Player 确认 872K 表示上下文窗口值。Provider/model ID 和运行时需在任务需要时核验。Picker 选择不证明模型实际运行。

Andon 与日期刷新

暂停并请 Player 选路径日期基线 stale，且 Git / editor 状态 dirty、behind 或 unknown 时。暂停受影响的写入；不得 stash、reset、pull、覆盖或静默刷新。
只在批准后刷新先将刷新前完整 Repo/today.md 归档到以前一日命名的 Repo/days/YYYY-MM-DD/today.md；再更新 today.md，随后更新 now.md。日常启动不改写 INTENT.md。
复核后关闭Player 选定路径并完成、复核后，关闭该 ANDON。保留已知 dirty paths；不要求清理、commit 或 push。允许不触及、不覆盖、不依赖这些路径的任务。
不推断远端同步默认不 fetch。Repo commit 对齐需在获批后 fetch 所选分支并比较 HEAD；不 merge、pull、commit 或 push。

证据边界

  • 当前日期、Repo commit alignment、worktree/editor dirty、Dojo 路径和归档状态要分别核验；未知不推断为通过。
  • 终端 cwd 与 workspace 是两项事实；Profile、Settings Sync、插件、设备、订阅声明、picker 和真实 backend 不互相代证。
  • Player/Human 声明可以支持有来源的 pass，但不标为 SI 独立测量。Sol 是 Mission workload，Luna 是软件维护 workload；不自动切换模型。未知模型 ID 只阻断依赖它的任务。
  • scripts/verify.py 的结构通过不等于 A1-A13 全部通过；Human review、role alignment 和真实模型运行分别留证。
  • scripts/mirror.py 只用于显式授权的确定性 MPS artifact。Narrative Page 不是 MPS artifact，也不自动生成或写回来源。
  • 评估完成后写入 JSON evidence 与 HTML 回执：READY、READY_WITH_LIMITS、BLOCKED 均适用；写入被禁止的未解决 ANDON 期间不生成。JSON 和原始来源承载证据，HTML 只作可视化索引。
