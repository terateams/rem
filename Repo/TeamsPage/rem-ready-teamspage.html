开工路线

01 · BIND对齐任务与日期读取 today、now、INTENT、EGO quartet；绑定唯一 Primary、EVAL、Secondary=0 与时区。
02 · INSPECT检查现场，不推测Git、编辑器缓冲、Dojo、终端 cwd、VSC/Profile/Sync/extensions 与必要 runtime 分别核验。
03 · HAND OFF验证并说明下一步读 verify.py 实际结果；未知标 unknown，未执行标 not_run，交接不替代 Human 判断。

当前任务绑定还必须满足 INTENT 与 Mission 的 scope、责任位、证据、EVAL、permission、cost 和 stop rule。Picker 可见或扩展已安装，不等于实际模型运行。

Andon 与日期刷新

暂停并请 Player 选路径日期基线 stale，且 Git / editor 状态 dirty、behind 或 unknown 时。不得 stash、reset、pull、覆盖或静默刷新。
只在批准后刷新先将刷新前完整 Repo/today.md 归档到以前一日命名的 Repo/days/YYYY-MM-DD/today.md；再更新 today.md，随后更新 now.md。日常启动不改写 INTENT.md。
不推断远端同步默认不 fetch；只比较现有本地 refs。未 fetch 时，远端新鲜度仍为 unknown。

证据边界

  • 当前运行日期、Git 状态、分支 ahead/behind、editor dirty、Dojo 路径和归档状态要分别核验。
  • 终端 cwd 与 workspace 是两项事实；Profile、Settings Sync、插件、设备、订阅声明、picker 和真实 backend 不互相代证。
  • Sol 是 Mission workload，Luna 是软件维护 workload；不自动切换模型。无 task binding、permission 或 budget 时，停止相应 action。
  • scripts/verify.py 的结构通过不等于 A1-A13 全部通过；Human review、role alignment 和真实模型运行分别留证。
  • scripts/mirror.py 只用于显式授权的确定性 MPS artifact。Narrative Page 不是 MPS artifact，也不自动生成或写回来源。
